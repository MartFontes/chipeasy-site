# Trilha ENEM 0.4.1

Código completo com correção do acesso por HTTP na rede Wi-Fi.

Extraia o ZIP, abra um terminal na pasta `trilha-enem`, execute `npm ci` e depois `npm run dev:rede`. No celular conectado ao mesmo Wi-Fi, abra `http://IP-DO-COMPUTADOR:3100`. Veja o README do projeto para encontrar o IPv4 do computador. Requer Node.js 24 LTS.
